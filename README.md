# M4B Editor — legacy compatibility channel

Le développement et les téléchargements actuels sont dans **[aruel-perso/m4b-editor](https://github.com/aruel-perso/m4b-editor)**.

Ce dépôt conserve les anciennes URL de téléchargement et le canal de mise à jour signé des installations m4b-Craft 0.2/0.3. Les anciens noms des fichiers sont intentionnels : les anciens clients refusent les redirections et exigent ces identifiants.

Historical releases, their original assets and source tags are retained here. This is a release compatibility endpoint, not a separate development fork. New users should install M4B Editor from the canonical repository. Both channels retain the corresponding GPL sources and license notices.
